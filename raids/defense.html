How It Works

Protect the Core

A run has up to 1,000 waves of 5 enemies. They walk toward the core, which sits inside your attack radius. If you don't defeat the whole wave in 60 seconds, it reaches the core and the run ends for everyone.

Safe From Hits

These enemies never hit you, so you can't die here. There are no boss waves.

Enemy HP

Every wave has ×1.1 the HP of the one before. HP is the same for every player and does not depend on your world.

Playing Together

Your own run starts the moment you enter. Other players on your server can join it from the run list for the first 60 seconds, each with their own key. There is no player limit except the server size.

Rewards in a Shared Run

Each player gets rewards for every wave cleared while they are in the run. If you join late, earlier waves do not count for you.

Bonuses

Nothing boosts Battle Tokens yet. Coins and XP use your usual bonuses, and the token number is boosted by Drops. You keep everything you earned when the run ends.

Achievements and Leaderboard

Other Achievements

Every enemy counts for Enemies Defeated, for each player in the run. Defense does not count for the Raids achievement or the Bosses achievement.

Weekly Board

The board shows your best run of the week by waves cleared. In a tie, the faster player ranks higher. It covers all servers, resets every Monday at 0:00 UTC and has no prizes. A shared run counts the same way as the achievement.
