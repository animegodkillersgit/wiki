Boss Rush

Boss Rush is a solo fight against bosses that come one at a time, each much stronger than the last.

How It Works

One Boss at a Time

A run has up to 1,000 bosses, and you get 60 seconds for each one. If a boss survives, the run ends. Each boss has ×2 the HP of the one before.

Solo Only

Every player has their own run. Nobody can join you, and you can't join anyone else.

Dying

Bosses hit you. If you die, you respawn on the spot and fight the same boss with the same HP. Its timer keeps running.

Rewards

RewardAmountChanceWhen
Hero Token130%Each boss defeated

Bonuses

The X2 Hero Tokens gamepass, the Hero Token potion and VIP boost this reward. Luck and Drops do not.

Only Hero Tokens

You get each reward the moment a boss dies, and you keep it when the run ends. Boss Rush gives no coins, XP or tokens.

Achievement

Boss Rush Achievement

Each level is earned by defeating that many bosses in a single run. Bosses from different runs do not add up.

Bosses and Leaderboard

Bosses Achievement

Boss Rush bosses count for the Bosses achievement. Boss Rush does not count for the Raids achievement.

Weekly Board

The board shows your best run of the week by bosses defeated. In a tie, the faster player ranks higher. It covers all servers, resets every Monday at 0:00 UTC and has no prizes.
